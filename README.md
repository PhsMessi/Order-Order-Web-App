A simple, web-based point-of-sale (POS) and reservation system project. Built with Html, CSS, JavaScript, Nodejs, and Mysql. this simple web application project provide a simple real-world order algorithm.

Features (Admin): 
1. Real-time POS Sytem
2. Dual payment options
3. Quick cash selection
4. Change Calculator
5. Complere Order logs


Features (Customer UI)
1. Pre order functionality
2. Scheduled pick-ups
3. Order email confirmation
4. order summary
5. Dual payment options

This project is a beginner friendly anyone can clode or contribute to the project

just a practice project for learning javascript, nodejs and mysql.
